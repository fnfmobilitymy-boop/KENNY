# M2 refinement — Kenny AI Business Studio

## Preserved

The existing K-inspired polygon symbol, `/design-system` route, theme toggle, button/card/field primitives, native dialog, keyboard tabs, typed future service contracts, static-export option and contrast tests remain. The repository was clean before this work. A new `AGENTS.md` was generated by Next.js during development; its version-specific guidance is retained.

## Refined

- Shared `Brand` component standardizes visible branding as **Kenny AI Business Studio**. The repository and deployment path remain `KENNY`.
- Violet-blue gradient endpoints replace the rose gradient. Semantic dark/light colors are preserved; glass, glow, blue and input-stroke tokens extend the system.
- Subtle glass treatment is limited to the header and dashboard frame, with opaque fallbacks. Slow-update/reduced-motion modes remove backdrop filtering and animation.
- `ButtonLink` shares the same size, shape and state styling as existing buttons. Links navigate; buttons perform actions.
- Visible input boundaries use a dedicated contrast token; placeholder color uses the theme's muted text.

## Typography evaluation

Inter is selected for body text, navigation and controls: its familiar letterforms keep dense product information readable. Space Grotesk is selected for display headings and the wordmark: its distinctive shapes support the futuristic direction without imposing that style on small text. The design-system page displays both for review.

Both variable fonts are sourced from pinned Fontsource npm dependencies and loaded locally through `next/font/local`. Only normal Latin WOFF2 files are bundled; no Google Fonts or other runtime font request is needed. Font display is `swap`; Next.js metric-adjusted Arial fallback reduces shifts while font files load. Inter falls back through the system sans stack; headings fall back through Space Grotesk/Inter/Arial. CJK content uses available system glyphs. Font licenses remain in their npm packages (OFL).

## Validation

Lint, strict typecheck and the existing contrast tests passed after refinement; the extended six-test suite also passes. Browser and final production results are recorded in `PHASE_1_ACCEPTANCE.md`. An initial Fontsource subset import failed because that package path does not exist; local WOFF2 loading replaced it. No TLS or artifact verification was bypassed.
